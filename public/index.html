AirdeskLogger

This is the API for an EASA flight crew logbook (AMC1 FCL.050). It is a backend service, so there is no user interface here. The endpoints below are served as serverless functions.

All times are handled in UTC. Times that are not expressed in UTC are rejected.

EndpointMethodWhat it does
/api/health GET Reports that the service is running.
/api/validate POST Validates one flight entry and returns the twelve derived column values.
/api/logbook-pdf POST Renders a set of entries to a PDF in the EASA paper layout.

Storage endpoints (creating, amending and signing entries) require a configured PostgreSQL database and are added once a connection is provisioned.
